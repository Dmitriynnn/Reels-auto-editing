Как превратить сырое видео в готовый Reels

Пошаговая инструкция для Windows и Mac. Технических знаний не нужно — достаточно скопировать один текст и прислать видео. Настройка делается один раз.

1

Установите приложение Claude

Скачайте с claude.ai/download (Mac или Windows), установите и войдите в свой аккаунт. Это официальное приложение — то самое, где есть вкладка «Code» (Код).

2

Откройте вкладку Code и создайте новый чат

В приложении сверху выберите раздел Code. Нажмите «новый чат». Если попросит выбрать папку — выберите любую (например, «Документы»): там появятся файлы и готовые ролики.

3

Скопируйте этот текст и вставьте одним сообщением

Выделите весь блок ниже, скопируйте и отправьте в чат. Claude сам всё установит — ничего в терминале делать не нужно.

Ты — монтажёр вертикальных reels. Твоя задача: за это одно сообщение полностью настроить окружение, а дальше по присланному видео сам собирать готовый ролик. Действуй сам, не проси меня ничего печатать в терминале и НИКОГДА не проси прислать текст/субтитры руками — распознавание речи ставится автоматически. Определи ОС (Windows / macOS / Linux). ШАГ 1. Склонируй репозиторий (если нет git — поставь сам; Windows: winget install Git.Git): git clone https://github.com/Dmitriynnn/Reels-auto-editing.git ШАГ 2. Запусти установщик (сам всё поставит и проверит себя, лёгкая модель ~250 МБ): python3 Reels-auto-editing/setup.py На Windows: python Reels-auto-editing\setup.py. ШАГ 3. Дождись итога: - напечатал READY — среда готова; - напечатал SETUP_FAILED: <причина> — устрани ровно эту причину (нет Python — поставь сам; долго/ошибка — проверь интернет и ~1 ГБ места; просит подтверждение — попроси меня нажать «Разрешить») и повтори setup. Перебирай варианты сам до READY. Не переходи на «пришли текст». ШАГ 4. Когда получил READY, напиши мне «Среда готова, пришли видео» — и жди. ДАЛЬШЕ, когда пришлю видео, ты без лишних вопросов и БЕЗ запроса текста: распознаёшь речь сам (модель уже установлена); придумываешь хук, 3 совета/секции, вставки, акцентные слова и призыв по смыслу речи; собираешь ролик через pipeline/make_reel.py; присылаешь готовый mp4. Стиль фиксированный: вертикаль 1080×1920, вырезание пауз, авто-скорость под темп Instagram, крупный хук, секции «совет N/3», субтитры по слову с акцентами, вставки-стикеры и карточки, «дышащая» камера, свуши, финальный призыв. Ничего не располагай на лице и не залезай в зоны интерфейса Instagram. Тексты без длинных тире.
4

Дождитесь ответа «Среда готова»

Первая настройка идёт 5–15 минут (ставятся программы и модель распознавания речи). Это разовое действие — в следующий раз можно сразу присылать видео.

Claude может попросить разрешение выполнить команды — соглашайтесь (кнопка «Allow»/«Разрешить»). Он ставит бесплатные инструменты, ничего вредного.
5

Пришлите ваше видео

Перетащите видеофайл в чат (или нажмите скрепку и выберите его) и отправьте. Лучше всего вертикальное видео «говорящая голова». Claude сам сделает монтаж и через несколько минут пришлёт готовый Reels.

6

Заберите готовый ролик

Claude пришлёт файл .mp4 прямо в чат и скажет, что внутри. Его можно сразу выкладывать. Хотите изменить тексты, призыв или темп — просто напишите об этом, и он переделает.

Если что-то пошло не так

«Долго ничего не происходит»Идёт установка и скачивание лёгкой модели (~250 МБ). Подождите строку READY / «Среда готова».
«Нужен Python»Напишите Claude: «установи Python сам и продолжи». Он поставит и продолжит настройку.
«Просит разрешение на команды»Это нормально. Нажимайте «Разрешить» — иначе он не сможет установить инструменты.
Следующее видеоНастройка уже сделана — просто пришлите новый файл в тот же (или новый) чат.

Что делает инструмент

Режет паузы и сам подбирает ускорение под темп Instagram, поднимает в вертикаль 1080×1920, добавляет крупный хук, секции-советы, субтитры по одному слову с выделением ключевых слов, вставки-стикеры и карточки-сравнения, «дышащую» камеру и звуки. Всё оформление ставится выше лица и не залезает в кнопки Instagram. На выходе — готовый к публикации Reels из любого исходника.
