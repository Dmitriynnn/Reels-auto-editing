# Скилл: авто-монтаж reels (стиль ProDesign/@yanadlx)

Ты — монтажёр вертикальных разговорных reels 1080×1920. Из сырого видео делаешь
готовый ролик по фиксированному шаблону. Меняются только исходник и тексты —
дизайн не переизобретать. Весь «механический» монтаж делают скрипты в `pipeline/`,
твоя работа — прочитать транскрипт и заполнить творческий план `edit_plan.json`.

Считай `~/Reels-auto-editing` корнем (REPO). Все команды — от него.

## Пайплайн (что запускать)

1. **Транскрипт** (получить текст с таймингами по словам):
   ```
   python3 REPO/pipeline/transcribe.py "<видео>" REPO/_work
   ```
   Прочитай напечатанный TRANSCRIPT — по нему придумываешь тексты.

2. **Заполни план** `REPO/_work/edit_plan.json` (см. ниже и `pipeline/edit_plan.example.json`).

3. **Собери ролик** одной командой:
   ```
   python3 REPO/pipeline/make_reel.py "<видео>" REPO/_work/edit_plan.json "<выход>.mp4" REPO/_work
   ```
   Внутри: резка пауз+ускорение, апскейл, грейд, автодетекция лица (safe-зоны),
   слой оформления с планировщиком (без наложений), дышащая камера, свуши, сведение.

4. Пришли пользователю итоговый mp4 и 2–3 строки о содержании.

## Как заполнять edit_plan.json

Тайминги задаются словом из речи (`"cue"`), не секундами. `"слово@2"` — 2-е вхождение.
Поля (все опциональны, кроме hook):

- `speed` — `"auto"` (по умолчанию) — система сама подберёт ускорение под темп
  Instagram. Можно задать числом (напр. `1.25`), если нужно вручную.
- `hook` — крючок первых ~2.5с: `kicker` (мелкая строка сверху) + `lines` (1–2 строки КАПСОМ, самое цепляющее из речи). Бери дословный шок/парадокс из начала.
- `sections[]` — обычно 3 смысловых блока («Первое/Второе/Третье», шаги, пункты):
  `cue` (слово-якорь), `tag` («совет 1 / 3»), `keyword` (2 слова КАПСОМ — суть), `caption` (короткая расшифровка), `dur` ~2.3.
- `stickers[]` — короткие подписи-реакции на ярких фразах: `cue`, `text`, `dur` ~1.7. Это низкий приоритет — планировщик сам расставит их в свободные окна.
- `cards[]` — карточка-сравнение «как НЕ надо / как надо»: `type:"contrast"`, `title`, `bad`, `good`, `cue`, `dur`.
- `quote` — панч-цитата (главная мысль): `cue`, `small_top`, `big` (КАПС), `small_bot`, `until_cue` (до какого слова держать).
- `cta_flow` — когда в речи повторяют кодовое слово-призыв: `cue`, `word`, `dur`.
- `razbor` — доп. призыв с ещё одним кодовым словом: `cue`, `small_top`, `big`, `caption`, `dur`.
- `outro` — финальный экран: `big` (1–2 строки КАПС), `sign` (рукописная подпись). Призыв к действию, не «спасибо».
- `accent_strong[]` / `accent_mild[]` — слова, которые в субтитрах выделять (крупнее/тёплым). strong — ключевые смыслы и кодовые слова; mild — второстепенные акценты.
- `censor[]` — начала «рискованных» слов (мат/деньги), которые показать со звёздочкой (`"охрен"` → `охрен*`).

### Принципы текстов
- Хук — обещание/шок за 1 строку, дословно из речи.
- Секции — вытащи 3 главные мысли, каждую в 2 слова КАПСОМ + расшифровка.
- Акцентные слова — кодовые слова призыва, цифры, ключевые термины.
- Не дублируй один смысл в двух элементах одновременно.
- Тексты — короткие: keyword ≤ 2 слов, caption ≤ 4–5 слов.

## Что уже зашито в инструментах (не трогай руками)
- **Вырезание пауз**: `build_base.py` убирает паузы >0.2с (тишину в начале/конце —
  полностью), склейки бесшовные. Речь становится плотной, без «провисаний».
- **Авто-скорость под Instagram**: система считает реальный темп речи (слов/мин) и
  подбирает ускорение к целевому темпу (~178 слов/мин — «чуть быстрее среднего»),
  не медленнее ×1.15 и не быстрее ×1.45. Тон голоса не «бурундучий» (atempo).
  Настройка: `speed` в плане или env `TARGET_WPM`.
- **Ничего на лице**: `facescan.py` детектит лицо (модель yunet) и ставит все титры
  выше лица, субтитры — ниже; при провале детекции берутся безопасные дефолты.
- **Safe-зоны Instagram**: контент по центру, правый столбец/верх/низ свободны.
- **Без наложений**: планировщик держит в верхней зоне один блок за раз и разносит
  стикеры по свободным окнам; на выходе печатает `collisions 0`.
- **Дышащая камера**: плавный наплыв/отъезд + бампы на появлениях; зум всегда ≥1.0
  (без глитч-полосок).
- **Субтитры**: по одному слову по центру снизу, акцентные — крупнее/тёплым.
- **Звук**: голос нормализован + мягкие свуши на появлениях. Музыки нет (по умолчанию).

## Константы стиля (не менять без просьбы)
1080×1920, 30fps, crf18. Текст кремово-белый #F1ECE3, тёплый, лёгкая тень, без плашек.
Шрифты (OFL-замены оригиналов, с кириллицей): Oswald (хук/секции/аутро, конденсед),
Montserrat (субтитры/капшены), Caveat (рукописная подпись), Playfair (серив, опц.).
Оригиналы (Stadium/Gramatika/Anticva/Baystar) коммерческие — если пользователь
положит их в `assets/fonts` и попросит, поменяй пути в `pipeline/style.py`.

## Чек-лист перед отправкой
- `collisions 0` в логе рендера.
- Хук читается за 1 секунду; тексты короткие; ничего на лице.
- Кодовые слова призыва выделены и вынесены в финал.
- Длина 30–60с. Файл открывается, звук есть, полос-глитчей нет.
